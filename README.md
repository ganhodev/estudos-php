# 📚 Estudos de PHP

Repositório de anotações pessoais do meu aprendizado em PHP.  
Os arquivos **não são feitos para execução** — funcionam como um caderno de consulta rápida, com explicações e exemplos comentados.

## 📂 Estrutura

| Arquivo | Conteúdo |
|---|---|
| `conceitos-basicos.php` | Sintaxe, variáveis e tipos de dados |
| `estruturas-condicionais.php` | if/else, switch, for, foreach |
| `funcoes.php` | Declaração de funções, parâmetros e retorno |
| `arrays.php` | Arrays indexados, associativos, multidimensionais e funções úteis |

> Este repositório é atualizado conforme avanço nos estudos.
